# Evolutionary analysis section

This directory contains the downstream analysis code for the **Uni-RNA** model. These scripts demonstrate how to utilize Uni-RNA embeddings to perform evolutionary analyses, including clustering, phylogenetic tree construction, visualization, and trajectory inference (pseudotime analysis).



## Data Preparation

* **Embeddings:** Ensure first generate Uni-RNA embeddings and save the embeddings correctly (e.g., `.pt` tensors for Python, `.csv` matrix for R).

* **Metadata:** The scripts assume specific column names (e.g., `family`, `clade`, `sample`, `id`). Please adjust the column names in the code to match your specific metadata file headers.

  

## File Description

### 1. `cluster&tree.py`
**Function:** Clustering, Visualization, and Tree Construction.
This Python script is the primary entry point for processing raw embeddings. It performs the following tasks:
*   **Clustering:** Performs K-Means clustering on the embeddings and calculates the Adjusted Rand Index (ARI) to evaluate performance against ground-truth labels (e.g., virus families).
*   **Dimensionality Reduction:** Uses t-SNE to visualize the high-dimensional embeddings in 2D space.
*   **Tree Construction:** Calculates a cosine distance matrix from the embeddings and constructs a phylogenetic tree using the UPGMA algorithm.

**Usage:**
1.  Open the script and update the file paths for `emb_dir` (your `.pt` embedding file) and `meta_dir` (your `.csv` metadata).
2.  Run the script:
    ```bash
    python cluster&tree.py
    ```
**Output:** `uniRNA_tSNE.svg` (Plot), `tree_ur.nwk` (Newick tree file).

---

### 2. `plot_tree.R`
**Function:** Phylogenetic Tree Visualization.
This R script visualizes the Newick tree file generated by the Python script (or any standard tree file). It creates a circular phylogenetic tree annotated with sample groups.
*   **Visualization:** Uses `ggtree` to draw a circular tree with colored tips based on taxonomic families.
*   **Evaluation:** Evaluates the hierarchical clustering of the phylogenetic tree by comparing the cophenetic distance to metadata labels using ARI.

**Usage:**
1.  Ensure you have `tree_ur.nwk` (generated from the Python script) and your metadata CSV ready.
2.  Run in R or RStudio.
**Output:** `tree_ur.svg` (High-quality tree visualization).

---

### 3. `trajectory_pseudotime.R`
**Function:** Evolutionary Trajectory and Pseudotime Inference.
This R script uses **Monocle3** to infer evolutionary trajectories based on the embeddings. It is particularly useful for analyzing viral evolution steps (e.g., SARS-CoV-2 variants from 19A to Omicron).
*   **Trajectory Learning:** Learns the graph topology of the embeddings.
*   **Pseudotime:** Orders cells (samples) starting from a specified root (e.g., clade '19A') to determine evolutionary pseudotime.
*   **Correlation:** Calculates the Spearman correlation between the inferred pseudotime and the known chronological order of clades.

**Usage:**
1.  Prepare `used_meta.csv` and `emb.csv`.
2.  Ensure the `root_cells_idx` in the script matches your starting strain/clade (currently set to '19A').
3.  Run in R or RStudio.
**Output:** `true_label.pdf` (UMAP colored by clade), `pseudotime.pdf` (UMAP colored by evolutionary time).
